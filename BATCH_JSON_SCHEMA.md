# MF MPanel Evidence — JSON Batch Schema Documentation

The Android application imports JSON batches generated by the MF MPanel website.

## Schema Definition

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "BatchImportJson",
  "type": "object",
  "required": ["links"],
  "properties": {
    "batchId": {
      "type": "string",
      "description": "Unique identifier for the evidence collection batch (e.g. BATCH-20261015-01)"
    },
    "batchName": {
      "type": "string",
      "description": "Human-readable title or campaign name"
    },
    "createdAt": {
      "type": "string",
      "format": "date-time"
    },
    "createdBy": {
      "type": "string",
      "description": "Email or UID of administrator"
    },
    "links": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["linkId", "url"],
        "properties": {
          "linkId": {
            "type": "string",
            "description": "Original unique Link ID (e.g. A01, LINK-99)"
          },
          "url": {
            "type": "string",
            "format": "uri",
            "description": "Target webpage URL"
          },
          "platform": {
            "type": "string",
            "enum": ["Instagram", "Facebook", "TikTok", "YouTube", "X", "Other"],
            "description": "Social or web platform tag"
          },
          "profileId": {
            "type": "string",
            "description": "Target handle or user identifier (e.g. @account)"
          },
          "postIdentifier": {
            "type": "string",
            "description": "Optional media or post ID"
          },
          "requiredScreenshots": {
            "type": "integer",
            "default": 1,
            "minimum": 1
          },
          "notes": {
            "type": "string",
            "description": "Investigation or compliance instructions"
          }
        }
      }
    }
  }
}
```

## Backward & Fallback Compatibility

If an array of link objects is provided without a root object (e.g. `[ { "linkId": "A01", "url": "..." }, ... ]`), the app automatically assigns a unique batch ID (`BATCH-<timestamp>`) and imports all links safely into the local Room database.
Existing captured screenshots are never erased when re-importing a batch.
